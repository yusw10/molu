# 명세: 방명록 v1

## 목적
하객이 모바일에서 축하 메시지를 남길 수 있도록 합니다.

## 사용자 시나리오
하객은 이름과 메시지를 입력해 빠르게 등록할 수 있어야 합니다.

## 입력
- 이름
- 메시지
- 참석 여부(선택)

## 출력
- 등록 성공 안내 문구
- 최신순 목록에 새 항목 표시

## 예외 케이스
- 빈 값은 거부해야 함
- 길이 초과는 거부해야 함
- API 실패 시 재시도 안내 필요

## 완료 기준 (DoD)
- 모바일에서 폼이 정상 동작
- 프론트/백엔드 모두 검증 적용
- SQL 스키마 반영 완료
- 관련 문서 업데이트 완료 (`content-model`, `changelog`, `runbook`)
