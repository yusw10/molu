# 명세: 관리자 페이지 v1

## 목적
비개발자도 청첩장 콘텐츠를 수정/저장할 수 있는 관리자 페이지를 제공합니다.

## 접근 방식
- 청첩장 하단 `관리자 페이지` 버튼 제공
- 비밀번호 검증 후 `/admin` 진입
- 최초 1회 비밀번호 설정 지원

## 기능 범위
1. 이미지 첨부 및 저장
- 메인 첫 화면 이미지
- 부부 소개 이미지
- 예식장 이미지
- 갤러리 3장
- 영상 URL

2. 정보 입력 및 저장
- 부부/부모님 이름
- 예식 일시/장소/주소
- 연락처
- 계좌 정보
- 공유 링크/문구
- 스토리 문구

3. 모바일 청첩장 추가 섹션
- 달력
- 지도 버튼(네이버/카카오)
- 부모님 소개
- 계좌 안내
- 카톡 공유
- 청첩장 링크 복사
- 네이버 지도 임베드 영역
- 갤러리 10장(3장 노출/클릭 확대/좌우 무한 순환)

4. 디자인 보완
- 메인 이름/날짜/장소 텍스트 가독성용 배경 칩 적용
- 달력의 예식일 하트 강조 스타일 적용

## 저장 방식
- Spring API를 통해 `site_settings.payload`에 JSON 저장
- 관리자 비밀번호는 BCrypt 해시로 저장

## 완료 기준 (DoD)
- `/admin`에서 저장 후 메인 화면 즉시 반영
- 비밀번호 없는 상태에서 최초 설정 가능
- 비밀번호 불일치 시 저장 거부
