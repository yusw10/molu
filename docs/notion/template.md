# Notion Template (copy and use)

## 1) Project Home
- Goal
- Timeline
- Current milestone
- Links to Git docs

## 2) Requirements
Columns:
- ID
- Feature
- Must/Should/Could
- Description
- Acceptance criteria
- Status

## 3) Content Source
- Greeting final text
- Date/time/place final text
- Family/contact text
- Account info
- Gallery source list

## 4) Sprint Board
Columns:
- Backlog
- In Progress
- Review
- Done

Each card should include:
- linked git branch
- linked spec file path
- checklist

## 5) QA Log
- device
- browser
- issue summary
- screenshot link
- result
