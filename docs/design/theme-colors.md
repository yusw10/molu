# 테마 색상

출처: 사용자 제공 팔레트 스크린샷 (2026-02-23)

## 팔레트
- Dry Sage: `#CCD5AE`
- Beige: `#E9EDC9`
- Cornsilk: `#FEFAE0`
- Papaya Whip: `#FAEDCD`
- Light Bronze: `#D4A373`

## 사용 규칙
- 기본 배경: `#FEFAE0`
- 카드/서피스: `#E9EDC9`
- 보조 강조: `#CCD5AE`
- 주요 강조: `#D4A373`
- 섹션 하이라이트: `#FAEDCD`

## 접근성 메모
- 밝은 배경에는 어두운 텍스트(`#2F2A24`) 사용
- 본문 글자 크기는 모바일 기준 최소 16px 유지
