# Theme Colors

## Palette
- Dry Sage: `#CCD5AE`
- Beige: `#E9EDC9`
- Cornsilk: `#FEFAE0`
- Papaya Whip: `#FAEDCD`
- Light Bronze: `#D4A373`

## Usage Rules
- Primary background: `#FEFAE0`
- Surface/card: `#E9EDC9`
- Accent soft: `#CCD5AE`
- Accent strong: `#D4A373`
- Section highlight: `#FAEDCD`

## Accessibility Notes
- Use dark text (`#2F2A24`) on light backgrounds.
- Keep body text at least 16px on mobile.
