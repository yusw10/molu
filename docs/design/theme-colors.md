# 테마 색상 (2026-02-24 개편)

밝고 가벼운 파스텔 분위기를 목표로 전면 재구성했습니다.

## 최종 팔레트
- 배경(Base): `#FFF9F4`
- 카드(Surface): `#FFFFFF`
- 블러시 핑크(Primary): `#F8DBE6`
- 파우더 블루(Secondary): `#E2EEFB`
- 민트(Soft Accent): `#DEF4EB`
- 살구(Highlight): `#FFE6CB`
- 강조(CTA): `#EA9FB5`
- 본문 텍스트: `#463B43`

## 사용 원칙
- 전체 배경은 밝은 아이보리 계열 유지
- 섹션 카드는 핑크/블루/민트를 교차 사용
- 버튼은 핑크-코랄 계열 그라데이션으로 통일
- 본문은 대비를 위해 딥 그레이 계열 텍스트 사용

## 폰트
- 제목: `Gowun Batang`
- 본문: `Gowun Dodum`

웹폰트는 Google Fonts CDN을 사용합니다.
